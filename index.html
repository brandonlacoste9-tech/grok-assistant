Grok Assistant · powered by xAI Grok

Personal AI chat with voice, vision, Imagine images & live weather

Grok Assistant is a clean dark-mode AI companion for everyday work and creativity. Stream answers from Grok, talk with Live speech-to-speech voice, attach photos for vision, generate art with Grok Imagine, check real weather, and keep memory and tasks on your device.

Features

  • Streaming chat with xAI Grok
  • Live voice (speech-to-speech) and push-to-talk STT / TTS
  • Image vision — ask about photos you attach
  • Grok Imagine — generate images, then download or copy
  • Live weather via Open-Meteo
  • Web & X search tools
  • Persistent memory, tasks, and plan-my-day
  • Clerk sign-in with per-user local history

FAQ

What is Grok Assistant?

A personal AI web app powered by xAI Grok for chat, voice, vision, image generation, weather, and productivity helpers.

Is the API key exposed in the browser?

No. Keys stay in Netlify serverless functions and never ship to the client.

Can it generate images?

Yes — use Imagine mode or prompts like “draw a cozy cabin,” powered by Grok Imagine.

Does weather work without Search mode?

Yes. Weather questions use Open-Meteo directly for live conditions and forecasts.
